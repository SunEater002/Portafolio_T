# Mi Portafolio

Este es un proyecto de portafolio personal diseñado para mostrar mis habilidades, proyectos y experiencia como desarrollador web. El portafolio está construido utilizando **HTML**, **CSS**, **Tailwind CSS**, y **AOS (Animate On Scroll)** para animaciones.

---

## Características

- **Diseño moderno y responsivo**: Adaptado para dispositivos móviles, tablets y computadoras.
- **Animaciones suaves**: Implementadas con la biblioteca AOS.
- **Secciones destacadas**:
  - Sobre mí
  - Habilidades
  - Proyectos
  - Contacto
  - Redes sociales
- **Enlaces interactivos**: Botones y enlaces con efectos de hover y transiciones suaves.
- **Desplazamiento suave**: Navegación fluida entre secciones.

---

## Tecnologías utilizadas

- **HTML5**: Estructura del contenido.
- **CSS3**: Estilización básica.
- **Tailwind CSS**: Framework de utilidades para estilos rápidos y consistentes.
- **AOS (Animate On Scroll)**: Biblioteca para animaciones al hacer scroll.
- **Netlify**: Despliegue de proyectos.
